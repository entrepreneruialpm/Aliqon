# Aliqon site conventions

- Every HTML page must include this Contentsquare tag inside `<head>` (just before `</head>`):
  `<script defer src="https://t.contentsquare.net/uxa/d4b372635f512.js"></script>`
  Add it to any new page.
- Use relative links between pages (`index.html`, `conjoint.html#...`), not root-absolute paths, so the site works under a GitHub Pages project URL.
