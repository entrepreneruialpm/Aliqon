# Aliqon Consulting website

Static one-page site. No build step.

- `index.html` – the home page
- `techno-economic-analysis.html` – techno-economic analysis service page
- `conjoint.html` – conjoint analysis service page
- `airtable-automations.html` – Airtable setup and automations service page
- `project-management.html` – project and program management service page
- `marketing-materials.html` – marketing materials development service page
- `project-chartering.html` – project chartering service page
- `portfolio-selection.html` – portfolio selection and management service page
- `kenny-portrait.jpg` – About section photo

## Publish with GitHub Pages
1. Push these files to the root of a repository.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. For a custom domain, add it under Settings → Pages (GitHub creates a `CNAME` file).
